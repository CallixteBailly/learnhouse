Comment on rejoint une organisation · tous les flux

Plateforme learn.ordria.fr · Organisation PROTECH (mode « sur invitation ») · établi le 27/09/2026

1 Les 3 portes pour entrer aujourd'hui

PROTECH est en mode fermé : personne n'entre sans y avoir été invité ou sans un code.

🚪 Porte 1 · Invitation par email En place
Backoffice PROTECH
Utilisateurs → Ajouter → « Inviter par email »
→
Email reçu
Lien d'invitation personnel (expire après 60 jours)
→
La personne clique
Crée son compte (ou se connecte si elle en a un)
→
✓ Membre apprenant
Accès immédiat aux cours
📍 Pendant l'attente, l'invitation apparaît dans la liste des membres avec le badge ambre « Invitation en attente » — elle disparaît dès que la personne rejoint. Tout survit aux redéploiements (stockage en base).
🚪 Porte 2 · Code de formation En place Le plus pratique pour un groupe
Backoffice PROTECH
Codes d'invitation → Générer (ex. RS6776-SEP)
→
PROTECH diffuse le code
Par email, WhatsApp, oralement… le canal choisi
→
Le stagiaire s'inscrit
learn.ordria.fr → s'inscrit → colle son code
→
✓ Membre apprenant
Chaque code peut être lié à un groupe
💡 Un code par promotion = une seule manipulation pour toute une session. Utilisable aussi bien à l'inscription qu'un compte existant (page « Rejoindre l'organisation »).
🚪 Porte 3 · Spontané (sans invitation) En place
Visiteur de la landing
Voit « Rejoindre l'organisation »
→
Page d'inscription
Un code d'invitation est exigé
→
✗ Sans code : bloqué
C'est voulu — PROTECH garde le contrôle
⇢
Détour : « Nous contacter »
Envoie un mail à support@protech-formation.fr
→
PROTECH invite
Retour à la porte 1 après accord

2 Une fois entré · qui voit quoi

Le rôle est attribué PAR organisation — la personne entre toujours comme apprenante, PROTECH la promeut ensuite si besoin (effet immédiat).

🎓 Apprenant
Cours, progression, certificats, boards
Rôle à l'entrée · pas d'accès au backoffice (les données protégées sont refusées par l'API)
✏️ Instructor
Ce que voit l'apprenant + création et édition des cours
Le formateur · pas de gestion des membres
🛠 Maintainer
Ce que voit l'Instructor + gestion étendue du contenu
Gestionnaire de contenu
👑 Admin org
Tout PROTECH + membres, rôles, réglages, analytics, codes d'invitation
L'équipe PROTECH
🔑 Superadmin
Toute la plateforme, toutes les organisations
Ton compte (anthony@ordria.fr) · dashboard /admin · clé maîtresse

3 Option B · file de demandes dans le backoffice À développer — sur demande

Pour laisser les gens se manifester spontanément et valider en un clic, en plus des 3 portes.

🟠 Demande à valider par PROTECH
Visiteur spontané
Bouton « Demander à rejoindre » (à la place du blocage)
→
Mini-formulaire
Nom, email, métier (2 champs déjà connus de l'inscription)
→
📥 File « Demandes »
Nouvel onglet dans Utilisateurs du backoffice PROTECH
→
✓ Approuver / ✗ Refuser
Approuver = membre immédiat + email de bienvenue
